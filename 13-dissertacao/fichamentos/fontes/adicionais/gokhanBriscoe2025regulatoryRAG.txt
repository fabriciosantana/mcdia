4.1.2 Graph Construction
We represent the corpus as a heterogeneous, di-
rected passage-level graph to encode both the doc-
ument structure and cross-document references.
Nodes. We create four node types: (1) Docu-
ment nodes for each regulatory document; (2) Pas-
sage nodes for atomic sections/clauses identified
by stable IDs (e.g., “6.1.2”); (3) NamedEntity
(NE) nodes for globally shared entities extracted
from the source JSON (NamedEntities); and (4)
DefinedTerm (DT) nodes for globally shared glos-
sary/definition items (DefinedTerms). Each pas-
sage node stores the raw text and its document
identifier.
Edges. We add typed, directed edges to cap-
ture structure and references: (1) CONTAINS
